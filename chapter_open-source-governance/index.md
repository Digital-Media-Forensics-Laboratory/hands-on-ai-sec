# 第六章  开源社区管理与开源生态发展

[全书目录](../index.md) · [首页](../README.md)

开源是以开放许可为基础，通过公开协作持续开发和完善软件的一种生产方式。开源项目通常向公众提供源代码，并允许使用者按照许可证规定进行使用、修改和再分发。开源社区是围绕开源项目形成的协作网络，发起人和维护者负责推进项目，其他开发者可以贡献代码和文档，普通使用者也能够反馈问题。随着项目影响范围扩大，企业和安全研究人员也可能参与其中，一些技术平台还会为社区提供协作和传播渠道。由于参与者往往来自不同组织，彼此之间不存在统一的行政隶属关系，社区需要依靠许可证明确基本权利，通过贡献规则和技术评审组织协作，同时借助版本管理与公开讨论维持项目运行。规模较大的社区还会设立专门的治理组织，负责协调项目发展和处理重要事务。

现代开源社区的规则体系在20世纪90年代末逐渐形成。1998年，开放源代码促进会（Open Source Initiative，OSI）[[151]](../chapter_references/index.md#ref-151)成立，由Eric Raymond和Bruce Perens共同创立，是推动开源理念传播、维护开源规则并开展许可证审查的重要非营利组织。OSI维护的《开放源代码定义》[[152]](../chapter_references/index.md#ref-152)（The Open Source Definition，OSD）进一步明确了开源许可应当满足的基本条件，包括允许自由再分发，提供可修改的源代码并允许形成衍生作品，同时不得针对特定个人、群体或者使用领域设置歧视性限制。这里的“开源”指符合OSD的软件许可口径；第二章对开放模型采用较宽的分析口径，纳入Open-weight和Restricted Open，不能据此认定这些模型许可证均符合OSD。这些规则将“开源”从较为宽泛的软件开发理念，转化为不同项目可以共同遵循的制度标准，也为开源社区处理软件使用、修改与传播中的权利关系提供了基础。

随着参与人数增加，单纯依靠创始人或少数核心维护者已经难以支撑大型项目长期运行，基金会逐渐成为开源社区重要的组织载体。Apache软件基金会（Apache Software Foundation，ASF）[[153]](../chapter_references/index.md#ref-153)成立于1999年，由此前围绕Apache HTTP Server形成的开发者群体发展而来，其设立的重要目的之一是为社区驱动的开源项目提供稳定的组织支持，使项目不只依赖个别志愿开发者，也能持续运行。Apache旗下项目主要通过项目管理委员会开展治理，由委员会负责项目方向、成员管理和正式版本发布，具体项目的决策权由长期参与社区建设的成员掌握。Linux基金会[[154]](../chapter_references/index.md#ref-154)（The Linux Foundation）则成立于2007年[[155]](../chapter_references/index.md#ref-155)，由开放源代码开发实验室（Open Source Development Labs，OSDL）与自由标准组织（Free Standards Group）合并形成。与Apache较具代表性的社区自治模式相比，Linux基金会更突出中立托管和产业协作，通过相对独立的组织平台连接开发者与企业，使存在不同利益诉求的参与者能够围绕共同的开源项目开展长期合作。基金会的发展推动开源社区从早期依靠个人和松散协作维持项目，逐步形成更稳定的组织治理机制。

随着互联网协作方式的发展，开源活动逐渐从项目内部延伸到更广泛的线上开发者社区。以GitHub[[58]](../chapter_references/index.md#ref-58)、GitLab[[156]](../chapter_references/index.md#ref-156)和Gitee[[157]](../chapter_references/index.md#ref-157)为代表的社区主要围绕代码和项目开展协作。开发者可以在其中发布项目，也可以反馈问题和贡献代码，并围绕项目共同完成开发工作。OSCHINA[[158]](../chapter_references/index.md#ref-158)和CSDN[[159]](../chapter_references/index.md#ref-159)等社区则更加侧重开源资讯传播与技术交流，为开发者分享经验和获取知识提供空间。不同类型的社区相互连接，使分散的开源项目和开发者逐渐形成更加广泛的协作网络，也为项目传播、协同开发和知识共享提供了重要支撑。目前，国内外已经形成一批规模较大且影响较广的开源与开发者社区，表6-1列出了其中具有代表性的社区及其主要功能。
